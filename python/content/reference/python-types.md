# Types cheat sheet

| Python | SQL analogue | Notes |
|---|---|---|
| `int` | INTEGER | arbitrary size |
| `float` | DOUBLE | binary approximation |
| `str` | VARCHAR | immutable |
| `bool` | BOOLEAN | `True` / `False` |
| `None` | NULL | test with `is None` |
| `list` | ARRAY | ordered, mutable |
| `dict` | a row / OBJECT | key → value |

```python
int("42"); float("3.5"); str(10); bool("")
```
