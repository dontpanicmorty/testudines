Complete the `app` in `solution.py` with two commands:

- `greet NAME [--upper]` prints `Hello, NAME!` (the whole line upper-cased with `--upper`).
- `repeat TEXT [--times N]` prints `TEXT` on its own line `N` times (default `2`).

```
greet Ada             -> Hello, Ada!
greet Ada --upper     -> HELLO, ADA!
repeat hi --times 3   -> hi / hi / hi
```
