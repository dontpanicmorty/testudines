`upsert_customers(conn, rows)` loads a batch of customer records `{id, email, updated_at}` (ISO date strings) into `customers(id INTEGER PRIMARY KEY, email TEXT, updated_at TEXT)`. Replaying a batch is already harmless. But when a **late-arriving, older** version of a customer shows up after a newer one, it clobbers the newer data. Fix it: the stored row only changes if the incoming `updated_at` is strictly newer. Return nothing.
