Write `first_integer(text)` that finds the first whole number in the text and returns it as an `int`. A number is one or more digits, and may have a minus sign directly in front. If there is no number, return `None`.

```python
first_integer("temp is -12 today")    # -12
first_integer("room 7 and 9")         # 7
first_integer("nothing")              # None
```
