A small program follows these written steps to budget for a party:

1. multiply the number of guests by the cost per guest
2. add the venue fee
3. add 10 percent on top of that total, for surprises

Write `party_budget(guests, cost_per_guest, venue_fee)` that returns the final budget.

```python
party_budget(10, 8, 20)    # 110.0
party_budget(0, 8, 20)     # 22.0
```
