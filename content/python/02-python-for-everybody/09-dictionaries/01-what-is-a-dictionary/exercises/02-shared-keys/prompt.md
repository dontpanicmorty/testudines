Two classes keep their own sign-up sheets, stored as dictionaries that map a student's name to a score. Write `in_both(first, second)` that returns a list of the names that appear in **both** dictionaries, sorted alphabetically. The scores do not matter.

```python
a = {"Ana": 1, "Ben": 2, "Cy": 3}
b = {"Cy": 9, "Ana": 8, "Dee": 7}
in_both(a, b)    # ["Ana", "Cy"]
```
