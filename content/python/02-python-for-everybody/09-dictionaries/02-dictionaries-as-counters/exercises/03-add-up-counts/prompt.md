Two shops each keep a dictionary of how many of each fruit they sold. Write `combine(first, second)` that returns a **new** dictionary with the total sold of each fruit across both shops. A fruit that appears in only one shop keeps its count. Neither input may be changed.

```python
combine({"fig": 2, "pear": 1}, {"pear": 4, "plum": 5})
# {"fig": 2, "pear": 5, "plum": 5}
```
