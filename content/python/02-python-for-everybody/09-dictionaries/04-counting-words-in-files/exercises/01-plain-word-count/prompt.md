Write `count_words(path)` that reads the text file at `path` and returns a dictionary mapping each word to how many times it appears. Words are the pieces you get from splitting on whitespace. Do not change capitalization or remove anything else.

If the file holds `"to be\nor not to be\n"` the answer is `{"to": 2, "be": 2, "or": 1, "not": 1}`.
