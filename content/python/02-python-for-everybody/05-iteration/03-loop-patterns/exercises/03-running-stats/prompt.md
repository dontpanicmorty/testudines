Write `summarize(numbers)`. Using a single loop, work out the count, the total and the largest value, and return them as a dictionary with the keys `"count"`, `"total"` and `"largest"`.

`summarize([3, 9, 4])` returns `{"count": 3, "total": 16, "largest": 9}`. For an empty list, return `{"count": 0, "total": 0, "largest": None}`. Do not use `len`, `sum` or `max`.
