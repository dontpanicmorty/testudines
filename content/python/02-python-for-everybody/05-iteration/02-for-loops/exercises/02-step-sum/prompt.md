Write `sum_stepped(start, stop, step)`. Add up the whole numbers that begin at `start` and move by `step` each time, stopping before they reach or pass `stop`. Return the total.

`sum_stepped(1, 10, 3)` adds 1 + 4 + 7 and returns `12`. If no numbers qualify, the answer is `0`. The step may be negative: `sum_stepped(5, 0, -2)` adds 5 + 3 + 1 and returns `9`.
