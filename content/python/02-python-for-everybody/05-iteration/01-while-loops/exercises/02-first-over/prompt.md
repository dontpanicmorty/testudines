Write `months_to_reach(goal, deposit, percent)`. You start with a balance of 0. Each month you first add `deposit`, then the balance grows by `percent` percent. Return the number of months until the balance is at least `goal`.

If `goal` is 0 or less, return `0` because no waiting is needed. Example: with a goal of 100, a deposit of 50 and 0 percent, the answer is `2`.
