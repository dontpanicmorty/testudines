Write `columns(d)` that splits a dictionary into two parallel lists: the keys sorted alphabetically, and the matching values in the same order. Return them as a pair `(keys, values)`. An empty dictionary gives `([], [])`.

```python
columns({"b": 2, "a": 1, "c": 3})    # (["a", "b", "c"], [1, 2, 3])
```
