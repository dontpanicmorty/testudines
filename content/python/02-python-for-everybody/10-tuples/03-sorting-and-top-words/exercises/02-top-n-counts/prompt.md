Write `top_n(counts, n)` that takes a dictionary of word counts and returns a list of the `n` most common `(word, count)` pairs, most common first. Words with equal counts are ordered alphabetically. If there are fewer than `n` words, return all of them.

```python
top_n({"tea": 3, "milk": 5, "rice": 3, "oat": 1}, 3)
# [("milk", 5), ("rice", 3), ("tea", 3)]
```
