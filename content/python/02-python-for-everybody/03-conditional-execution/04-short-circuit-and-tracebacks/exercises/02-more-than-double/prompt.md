Write `more_than_double(a, b)` that returns `True` if `a / b` is greater than 2 and `False` otherwise. When `b` is 0 the answer is `False`, and the function must not crash.

```python
more_than_double(10, 3)   # True
more_than_double(10, 5)   # False  (exactly 2 is not more than 2)
more_than_double(10, 0)   # False
```
