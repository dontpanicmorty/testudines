A cinema sets ticket prices like this:

- Children under 12 pay 5.
- Seniors aged 65 or over pay 6.
- Everyone else pays 10.
- Members of the cinema club get 2 off the price for seniors and for everyone else, but there is no discount for children (they are already cheap).

Write `ticket_price(age, is_member)` that returns the price.

```python
ticket_price(30, False)   # 10
ticket_price(30, True)    # 8
ticket_price(8, True)     # 5
```
