A year is a leap year if it is divisible by 4, except that years divisible by 100 are **not** leap years, unless they are also divisible by 400. Write `is_leap_year(year)` that returns `True` or `False`.

```python
is_leap_year(2024)   # True
is_leap_year(1900)   # False
is_leap_year(2000)   # True
```
