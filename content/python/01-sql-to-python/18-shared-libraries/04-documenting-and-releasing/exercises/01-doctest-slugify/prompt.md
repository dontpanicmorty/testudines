`slugify` builds URL-friendly names for reports. Its docstring is the specification: the `>>>` examples are checked with `doctest`.

Implement the function so every example passes, and add **at least one more example of your own** to the docstring (the tests count the examples and require at least 5 attempted).

Rules: lowercase; keep only letters and digits; words separated by one hyphen; no leading or trailing hyphens.
